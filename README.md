# Discord-Bot
Experimenting with python to create a star wars themed discord bot. The discord bot is themed after a B1 battle droid which were first seen in Episode I.

### Functionalities (as of right now)
* Responds to messages
* Basic slash commands
* Weather slash command using WeatherAPI.com

### What I learned
* How to use the discord.py API
* How to create a discord bot
* Python basics
* How to use an API key and parse JSON response
